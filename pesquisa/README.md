# Pesquisa de campo exploratória

- **Instrumento:** questionário on-line (Google Forms), revisado pelo orientador e testado previamente por um técnico do setor.
- **Público:** profissionais que trabalharam com equipamentos inverter nos últimos 2 anos.
- **Período:** 20/10/2026 a 05/11/2026 · **Respostas:** 7 (todas de SP).
- **Ética:** participação voluntária e anônima, mediante concordância com o texto de apresentação.
- **Limitação:** amostra pequena; os resultados são descritivos e não permitem generalização estatística.

`sintese_respostas.csv` traz apenas contagens agregadas. As respostas individuais não são publicadas.
